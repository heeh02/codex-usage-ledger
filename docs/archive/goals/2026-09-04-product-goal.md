## 1. 最终目标

把 Codex Usage Ledger 做成普通 Codex 用户无需理解内部实现即可使用的本地
macOS 用量产品。用户必须能够快速、无歧义地回答：

1. 某账号在指定周期总共使用了多少；
2. 某项目在指定周期使用了多少，以及该数字是否完整；
3. 独立对话及其 Subagent 使用了多少；
4. 某 Session 自身和整个子树分别使用了多少；
5. 当前数字来自官方、直接确认、历史重建、估算还是不可恢复缺口。

## 2. 产品原则

1. **一个页面只回答一个核心问题。** 总览、项目、独立对话、Session、账号与额度、数据质量不得继续复用同一长页面。
2. **一个周期只有一个主 KPI。** 选择近 7 天后，页面最醒目的数字必须是近 7 天，而不是今日、本周或累计。
3. **证据状态紧贴数字。** 任何大数字必须同时显示官方完整、官方下限、本机确认、重建下限、估算、待重建、未知或不可恢复。
4. **来源选择而不是来源相加。** `effective(thread, day) = choose(sampling, reconstruction)`；Sampling 与 reconstruction 永不直接求和。
5. **项目、独立对话、未匹配互斥。** 同一 Token 事实只能属于其中一类。
6. **隐私和辅助功能是发布门槛。** 视觉界面与辅助功能树使用同一脱敏结果；Session 主任务必须可由键盘和 VoiceOver 完成。
7. **高阶诊断渐进披露。** replay、counter epoch、quarantined 等实现细节只能进入数据质量的高级诊断区。

## 3. 固定信息架构

```text
总览
├── 账号总量
├── 本机归因覆盖
├── 全局趋势
└── 项目 / 独立对话排行

工作
├── 项目
│   ├── project-alpha
│   ├── project-beta
│   └── ...
└── 独立对话

账号与额度
├── 账号档案
├── 官方额度周期
└── 账号切换时间线

数据质量
├── 数据来源与新鲜度
├── 重建状态
├── 未匹配
├── 不可恢复
└── 高级诊断
```

Session 仅从项目或独立对话下钻，不作为一级导航。

## 5. 周期规范

- 今日
- 本周（自然周）
- 近 7 天（滚动）
- 本月（自然月）
- 近 30 天（滚动）
- 12 周
- 12 月
- 至今

主页面、侧栏、趋势、模型、组成和 Session 必须共享同一周期。侧栏不得维护独立
的周/月/总状态。每个周期必须显示实际起止时间。

## 6. 数据证据模型

| 状态 | 用户文案 | 计入范围 |
|---|---|---|
| Official | 官方账号数据 | 账号 Total |
| Confirmed | 已直接确认 | 本机归因 |
| Reconstructed | 已从历史恢复 | 有效归因下限 |
| Pending | 等待历史恢复 | 暂不计入 |
| Estimated | 保守估算 | 独立展示，不并入确认总量 |
| Unknown | 暂时无法判断 | 不计入 |
| Unrecoverable | 本机源已丢失 | 永久不计入本机归因 |

Token 恒等式：

- `input + output = total`；
- cache read / cache write 是 input 的子集；
- Reasoning 是 output 的子集；
- `项目 + 独立对话 + Token 未归属 = 本机有效归因`；
- 本机有效归因不冒充官方账号 Total。

## 8. 视觉规范

- 8px 间距网格；卡片内边距 16px；主区域最多两列；
- 页面标题 20–22px；卡片标题 15–16px；KPI 28–32px；
- 蓝色=官方，绿色=Sampling，紫色=Reconstruction，深青=有效归因，
  橙色=覆盖不足，灰色=未知/不可恢复；
- 每个大数字旁必须有证据徽章；
- 不允许用小字号免责声明修补错误的信息层级。

## 9. 隐私规范

默认智能脱敏：

- API Key、Token、密码和 Bearer 凭据；
- 本机绝对路径；
- 私网地址和含端口的内部地址；
- 邮箱、账号标识和超长命令参数。

视觉 DOM、导出、辅助功能树和截图使用同一脱敏函数。设置最终提供“智能标题 / 仅
会话编号 / 原始标题”三级，但原始标题不得作为默认值。

## 10. 禁止项

- 禁止在来源选择完成前把 reconstruction 与 sampling 相加；
- 禁止使用 `threads.tokens_used` 跨线程求和；
- 禁止把账号残差按项目比例分配；
- 禁止把全局账号组件放回项目、独立对话或 Session 页面；
- 禁止仅凭视觉截图宣称响应式、隐私或辅助功能通过；
- 禁止以测试通过替代真实安装版和独立黑盒验收。
